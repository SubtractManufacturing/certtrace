# New libraries ship one adjective-color-animal naming rule

New libraries get a single naming rule — adjective, color, then animal, joined by hyphens (e.g. `cute-purple-panda`) — backed by large shipped word lists so shops get millions of unique material IDs without a sequential number. Existing libraries keep the naming rules and word lists already on disk. Rejected: keeping family-code + animal + number as the default (sequential, not memorable); shipping the old preset catalog to new libraries (shops that want those shapes can build them in Advanced settings).
