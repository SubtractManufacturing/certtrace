# Printers are machine-local destinations

A Label Template is a library-owned recipe (size + content). Where a Label actually prints is a **Printer**: a shop-named destination on this computer that refers to one OS print queue. A template may have one Printer on this computer; that link lives in app settings, not `library.json`, so backups, restores, and other machines start unset. Only registered Printers are destinations (unique names; one OS queue is at most one Printer). After preview, CertTrace sends the PDF 1:1 at the template’s page size to that queue — no fit-to-page, no paper size on the Printer. Preview can add a Printer and, when Print was blocked, assign and send in the same step. Rejected: a printer id on the template / in the library; ad-hoc OS queues as destinations; fit-to-page scaling; silent one-click print without preview (ADR-0007). This supersedes the v0.1 “system print dialog via exported PDF” line in `planning/decisions.md`.
