## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Defaults: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` + `docs/adr/`. Scope is the desktop app only. See `docs/agents/domain.md`.

### Git commits

Use `.agents/skills/commit-pending-changes/SKILL.md` to split pending work into small commits. Message format: `.agents/skills/conventional-commits/SKILL.md` (also [CONTRIBUTING.md](CONTRIBUTING.md)).
